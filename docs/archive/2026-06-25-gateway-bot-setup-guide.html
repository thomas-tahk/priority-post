Part A · Create the Discord bot

1

Make an application

Go to the Discord Developer Portal → click New Application → name it (e.g. priority-post) → accept terms → Create.

2

Get the bot token DISCORD_BOT_TOKEN

Left sidebar → Bot. Then:

  • Click Reset Token → Copy. This is your DISCORD_BOT_TOKEN. (You only see it once — if you lose it, just reset again.)
  • Scroll to Privileged Gateway Intents → turn Message Content Intent ON → Save Changes.
▲

The #1 reason setups silently fail: if Message Content Intent is off, the bot connects fine but can't read a word you type — your messages just vanish. If it's not replying later, check this first.

3

Invite the bot to a server

Left sidebar → OAuth2 → URL Generator.

  • Under Scopes, check bot.
  • A Bot Permissions box appears below — check View Channels, Send Messages, Read Message History.
  • Copy the Generated URL at the bottom, paste it in your browser, pick a server you own (make a private one if needed), → Authorize.
4

Grab the two IDs DISCORD_CHANNEL_ID OWNER_DISCORD_ID

In the Discord app (not the portal): Settings → Advanced → Developer Mode → ON. Now right-click works:

  • Right-click the channel you want the bot in → Copy Channel ID → that's DISCORD_CHANNEL_ID.
  • Right-click your own name (any message or the member list) → Copy User ID → that's OWNER_DISCORD_ID.

Part B · Plug in & run

5

Paste the 3 values into bot/.env

Open /Users/tnt/Projects/priority-post/bot/.env and replace the three placeholders:

DISCORD_BOT_TOKEN=paste from step 2
DISCORD_CHANNEL_ID=paste from step 4
OWNER_DISCORD_ID=paste from step 4

Leave WEB_BASE_URL, INTERNAL_API_SECRET, and ANTHROPIC_API_KEY exactly as they are.

6

Start the bot

cd /Users/tnt/Projects/priority-post/bot
pnpm install
pnpm dev

You should see a "logged in as …" line and no errors. Leave this terminal running.

7

Talk to it in Discord

In the channel you picked, type:

what's next? add: call mom friday 3pm how am I doing? reschedule taxes to monday mark the dentist task done

It should reply with the ranked seed tasks and confirm each action it takes. Deletes ask for confirmation first.

If something's off

  • ›Bot online but ignores you → Message Content Intent is off (Step 2). Toggle it on, save, restart the bot.
  • ›Bot replies "401 / unauthorized" → INTERNAL_API_SECRET in bot/.env must equal testsecret (it already does — don't change it).
  • ›Bot can't reach the web app → the local server died. Restart it (box below).
  • ›No tasks show up → you're pointed at an empty DB; the seed lives in local Postgres on port 5433.
ⓘ

Restart the local web app if it stopped — from the repo root:

DATABASE_URL="postgresql://priority_post:priority_post_dev@localhost:5433/priority_post" \
INTERNAL_API_SECRET=testsecret \
pnpm dev
